Bilder für die Diashow hochladen

Diese Seite ist für alle, die Fotos zur Diashow beisteuern. Sie brauchen kein Konto und keine App, der Browser des Handys genügt (Safari auf dem iPhone, Chrome auf Android).

Was Sie brauchen

Beides bekommen Sie von der Person, die die Diashow betreut:

  • den Upload-Link: eine Webadresse, die auf /s/ und einen Code endet, oft auch als QR-Code;
  • das Upload-Passwort.

Hochladen

  1. Den Link auf dem Handy öffnen: in der Nachricht antippen oder den QR-Code mit der Kamera scannen.
  2. Das Upload-Passwort eingeben.
  3. Hochladen bzw. das + antippen, dann Fotomediathek bzw. Galerie wählen. Ein oder mehrere Bilder auswählen und bestätigen.
  4. Warten, bis jedes Bild als hochgeladen angezeigt wird, erst dann die Seite schließen.
Die Bilder erscheinen innerhalb etwa einer Stunde auf der Diashow.

Tipp: auf den Startbildschirm legen

Damit die Upload-Seite beim nächsten Mal mit einem Tippen aufgeht:

  • iPhone: Teilen → Zum Home-Bildschirm
  • Android: Menü ⋮ → Zum Startbildschirm hinzufügen

Gut zu wissen

  • Sie können nur hinzufügen. Die vorhandenen Bilder können Sie nicht sehen, ändern oder löschen, auch Ihre eigenen nicht. Soll ein Bild wieder weg, sagen Sie es der Person, die die Diashow betreut.
  • Fotos im JPEG-Format. Handys senden Fotos beim Hochladen über den Browser normalerweise als JPEG. Andere Dateien (Videos, Bildschirmfotos als PNG, iPhone-Fotos im HEIC-Format) zeigt die Diashow nicht.
  • Querformat füllt den Bildschirm am besten. Das Display ist klein und breit (3:2); Hochformat-Bilder bekommen seitlich Ränder.
  • Gibt es schon ein Bild mit gleichem Namen, bleiben beide erhalten; das neue bekommt eine Nummer im Namen.
