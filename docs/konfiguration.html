Konfiguration: config.yaml

Was das Gerät zeigt, steht in /mnt/stick/config.yaml auf dem USB-Stick. Die Datei wird bei jeder Runde neu gelesen: Eine Änderung wirkt nach dem aktuellen Bild bzw. der aktuellen Szene, ohne Neustart. Ohne die Datei zeigt das Gerät alle Bilder aus /mnt/stick/bilder nacheinander, endlos.

Aufbau der Datei

loop: true                 # nach dem letzten Schritt wieder von vorn

show_args:                 # Einstellungen für die ganze Show
  transitions: stack
  duration: 3
  easing: ease-out

cloud:                     # woher die Bilder kommen (ohne Passwort!)
  address: https://cloud.example.org
  user: diashow
  folder: bilder

sequence:                  # was nacheinander gezeigt wird
  - scene:
      text: Hallo
  - slideshow:
      minutes: 10
      shuffle: true
AbschnittPflichtBedeutung
sequencejaListe der Schritte: slideshow (Bilder) und scene (fliegender Text)
loopneintrue (Standard): danach wieder von vorn; false: einmal abspielen
show_argsneinEinstellungen der Diashow für alle Schritte (Übergänge, Uhr, Helligkeit …)
cloudneinAdresse, Benutzer und Ordner der Cloud, aus der die Bilder geholt werden

YAML in einer Minute

  • Einrückung zeigt, was zusammengehört. Nur Leerzeichen, keine Tabulatoren; alle Zeilen einer Ebene genau gleich weit eingerückt.
  • name: wert setzt eine Einstellung. Nach dem Doppelpunkt ein Leerzeichen.
  • - am Zeilenanfang beginnt einen Listeneintrag (einen Schritt).
  • # leitet einen Kommentar ein, der Rest der Zeile wird ignoriert.
  • true/false für Ein/Aus. Texte mit Sonderzeichen (: #) in Anführungszeichen: text: "Zeit: jetzt".
  • Kurzform für wenige Einstellungen: - slideshow: {minutes: 5, hold: 8}

loop

loop: true (Standard) spielt die Sequenz endlos. Mit loop: false endet sie nach dem letzten Schritt: Das Display wird schwarz, bis die Show neu gestartet wird (make restart oder Aus- und Einschalten).

show_args – Einstellungen für die ganze Show

show_args gilt für jeden slideshow-Schritt, solange der Schritt selbst nichts anderes sagt. Drei Schreibweisen sind gleichwertig: 

show_args:                     # 1. name: wert
  transitions: stack
  duration: 3
  shuffle: true
show_args:                     # 2. Liste
  - transitions stack
  - duration: 3
  - shuffle
show_args: --transitions stack --duration 3 --shuffle   # 3. wie auf der Kommandozeile
EinstellungStandardBedeutung
transitionscutÜbergang(e), mehrere durch Komma: stack (Fotostapel), cut (harter Schnitt), fade, wipe, push, blinds, dissolve, iris, zoom, split. Bei mehreren wird pro Bild zufällig gewählt.
duration2Dauer eines Übergangs in Sekunden
easingease-in-outGeschwindigkeitsverlauf: ease-in-out, ease-out, linear
hold10Sekunden pro Bild
shuffleauszufällige Reihenfolge
fillausBild füllt das Display (beschnitten) statt mit Rändern
pilean bei stackFotostapel: Bilder liegen als Abzüge mit weißem Rand übereinander
pile_turn0das darunterliegende Foto bis zu so vielen Grad gedreht (0–45)
clockankleine Uhr unten links (clock: false schaltet sie ab)
directory/mnt/stick/bilderOrdner mit den Bildern
seedzufälligfeste Zufallszahl: gleiche Reihenfolge und Übergänge bei jedem Start

Display-Einstellungen (clock, clock_hours, diagonal, gamma, limit, black, dither, size, seed) werden beim Öffnen des Displays gebraucht. Sie gehen nur in show_args, nicht in einzelne Schritte. Ändern sie sich, startet die Show von selbst neu (ein paar Sekunden schwarz).

cloud – woher die Bilder kommen

cloud:
  address: https://cloud.example.org   # öffentliche Adresse der Nextcloud
  user: diashow                        # Konto, mit dem sich der Pi anmeldet
  folder: bilder                       # Ordner dieses Kontos (Standard: bilder)
EinstellungStandardBedeutung
address–nur der Server, z. B. https://cloud.example.org (ohne https:// wird es ergänzt)
user–Benutzername des Kontos in der Nextcloud
folderbilderOrdner in diesem Konto, auch tiefer: Familie/Diashow
Kein Passwort in die config.yaml! Der Stick wird herumgereicht und ist schnell kopiert. Das Passwort liegt nur auf der SD-Karte des Pi (make diashow-setup). Ein Eintrag password: wird abgelehnt. Mehr unter Cloud einrichten.

Ohne cloud: holt der Pi die Bilder von dort, wo sie bei make diashow-setup eingerichtet wurden.

sequence – die Schritte

Jeder Eintrag ist ein Schritt, gezeigt von oben nach unten. Ein Schritt ohne Einstellungen: - slideshow oder - scene.

slideshow – Bilder zeigen

Alle Einstellungen aus show_args (außer den Display-Einstellungen) gelten auch hier, dann nur für diesen Schritt. Dazu:

EinstellungStandardBedeutung
minutesendlosDauer des Schritts. Ohne minutes läuft er endlos und muss der letzte Schritt sein.
directory/mnt/stick/bilderanderer Bilderordner nur für diesen Schritt

Die Bilder laufen über die Schritte hinweg weiter: Ein späterer slideshow-Schritt beginnt mit dem Bild nach dem zuletzt gezeigten, nicht wieder beim ersten.

scene – fliegender Text

Ein kleiner Text erscheint auf Höhe der Uhr, steigt in einem Bogen in die Mitte, wird dabei groß und färbt sich von Weiß über Gelb nach Rot. In der Mitte zerfällt er in Funken.

EinstellungStandardBedeutung
textXXXder fliegende Text, 1–40 Zeichen. Lange Texte werden in der Mitte kleiner, damit sie in die Breite passen.
repeat1wie oft; 0 = endlos (nur als letzter Schritt)
travel6Sekunden für den Flug in die Mitte
pause0,6Sekunden in der Mitte vor dem Zerfall
explode3Sekunden für den Zerfall
colorWeiß → RotEndfarbe als R, G, B (0–255), z. B. 30, 180, 10 für Grün
starting33, 4Startpunkt in Prozent: linke Kante von links, Unterkante von unten
timing0Sekunden nach dem Ende der vorigen Szene; negativ = überlappend (siehe unten)
background/mnt/stick/background/scene-background.jpgBild hinter der Szene; none = schwarz
seedzufälligfeste Zufallszahl für das Funkenmuster

Szenen-Blöcke und timing

Mehrere scene-Schritte direkt hintereinander bilden einen Block: ein gemeinsamer Hintergrund, kein Schwarz dazwischen. Mit timing startet eine Szene relativ zum Ende der vorigen:

  • timing: 0 – direkt danach
  • timing: 2 – 2 Sekunden nur Hintergrund dazwischen
  • timing: -3 – 3 Sekunden vor dem Ende der vorigen: Der neue Text steigt auf, während die Funken der alten noch verglühen.

Eine Szene beginnt nie vor dem Start der vorigen. Wiederholungen (repeat) folgen direkt aufeinander, timing gilt für die erste. Der Hintergrund des Blocks ist der der ersten Szene, außer eine spätere setzt ihren eigenen background.

Was gilt wann?

Gilt eine Einstellung mehrfach, gewinnt die spätere Stelle:

  1. eingebaute Standardwerte des Programms
  2. Standardwerte des Dienstes auf dem Pi (DEFAULT_ARGS: --transitions stack --duration 3 --easing ease-out)
  3. mit make config SHOW_ARGS="…" gespeicherte Einstellungen
  4. show_args in der config.yaml
  5. die Einstellungen des einzelnen Schritts

transitions: cut in show_args wirkt also genauso wie --transitions cut beim Dienst, und ein Schritt mit transitions: wipe nutzt nur dort wipe.

Prüfen und Fehler

make start und make restart melden eine fehlerhafte Datei sofort mit Grund. Ist sie in Ordnung, sagen sie nichts weiter. make status zeigt im Log, welche Sequenz gelesen wurde. Wird die Datei im laufenden Betrieb fehlerhaft gespeichert, bleibt die letzte gültige Version in Gebrauch.

Meldung (Auszug)Ursache
step 1 (scene): argument --starting: expected X,Y in percent, got '-6'falscher Wert, hier gemeint: timing: -6
'slideshow forever' never ends, so the steps after it would never playendloser Schritt nicht am Ende: minutes ergänzen
show_args: Unknown transition: fadeeTippfehler im Übergang
step 1 (slideshow): 'gamma' can't be set per stepDisplay-Einstellung gehört in show_args
cloud: unknown setting: passworddas Passwort gehört nicht in die Datei
not valid YAML: … line 4, column 4Einrückung stimmt nicht (Zeile 4)

Von Hand prüfen (auf dem Pi oder lokal im Quellcode-Ordner):

python3 sequence.py --config config.yaml --check

Vorschau als Film

Bevor eine neue Sequenz auf den Stick kommt, lässt sie sich als Film ansehen. Er wird mit demselben Programmcode erzeugt und ruckelt etwa so wie das echte Display: 

make movie CONFIG=config.yaml          # -> config.mp4
make movie CONFIG=config.yaml MOVIE_ARGS="--smooth --start 18:30"
